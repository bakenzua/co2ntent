# Calculate the apparent pK' of the CO2-Bicarbonate system in blood.

`douglas_apparent_pk_co2_hco3` calculates the apparent pK'of the
CO2-Bicarbonate in blood via the formula described by (Douglas et al.
1988) .

## Usage

``` r
douglas_apparent_pk_co2_hco3(temperature = 37, ph = 7.4)
```

## Arguments

- temperature:

  Plasma Temperature in Celsius. Default 37c

- ph:

  Plasma pH. Default 7.40

## Value

The apparent pK'

## References

Douglas AR, Jones NL, Reed JW (1988). “Calculation of whole blood CO2
content.” *J. Appl. Physiol.*, **65**(1), 473–477.
